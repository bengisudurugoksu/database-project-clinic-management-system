Atomic Transaction #1 — Patient Admission
Assigns a room AND creates an initial appointment in a single transaction. If either step fails, both are rolled back.
Room is assigned from today until the patient is discharged. Set the date & time below for the first doctor consultation.
How this transaction works
Atomic + Locking

BEGIN

SELECT Room, Doctor ... FOR UPDATE
Locks the critical rows before writes.
INSERT INTO RoomAssignment
Trigger marks room unavailable.
INSERT INTO Appointment
Creates the first consultation.

If both succeed → COMMIT
If either fails → ROLLBACK

This guarantees a patient is never assigned to a room without a corresponding appointment, and never has an appointment without a room.
