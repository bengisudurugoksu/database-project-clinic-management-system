How this transaction works
Atomic + Locking

BEGIN

SELECT RoomAssignment, Room ... FOR UPDATE
Locks the current assignment and destination room.
UPDATE RoomAssignment SET is_active=FALSE
Trigger frees the old room.
INSERT INTO RoomAssignment
Trigger reserves the new room.

If both succeed → COMMIT
If either fails → ROLLBACK

Without atomicity, a crash between steps would leave a patient with no room or two rooms simultaneously.
